# Phase 1 — Package Intake

Build the web shell, PostgreSQL schema, persistent artifact storage, jobs table,
single worker, ZIP upload, safe extraction, Skill selection, manifests,
readiness checks, immutable versions, task-file upload, file preview, and Skill
download.

Done when the UI can create v1, deduplicate the same ZIP, create v2 from changed
content, show exact file differences, reject unsafe archives, and download the
original/installable Skill without executing package content.
