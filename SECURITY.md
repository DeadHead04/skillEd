# Security policy

This project is in development in [DeadHead04/skillEd](https://github.com/DeadHead04/skillEd). A supported-release policy and private vulnerability reporting channel have not yet been established. No inherited upstream contact or response-time commitment is claimed.

Do not post credentials or an undisclosed exploit in a public issue. Share a reproduction privately with the repository owner through their confirmed channel. Include affected revision, runtime, steps, impact and possible mitigation, using redacted logs.

Agent engines, MCP servers and script judges execute code in the selected runtime. Use isolation appropriate to the workload. Keep provider keys in the supported credential configuration, out of committed YAML, command transcripts and report artifacts. Treat plugin observations and generated reports as potentially sensitive user data.
